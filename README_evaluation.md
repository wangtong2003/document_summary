# 摘要参数评估工具

这个工具用于评估大模型在不同参数配置下生成摘要的质量，帮助找出最佳参数组合。

## 评估指标

评估指标基于以下四个方面：

1. **信息准确性**（1分）
   - 检查摘要中是否存在数字错误、主体错误、事实错误、逻辑错误等
   - 按照正确率比例给分，例如：5条信息中有4条正确，得分为0.8分

2. **信息召回**（1分）
   - 结果展现80%以上的原文内容 = 1分
   - 结果展现60%的原文内容（有40%缺失）= 0.5分
   - 结果展现20%的原文内容（80%内容缺失）= 0分

3. **信息冗余**（1分/0分）
   - 摘要内容完全来源于原文 = 1分
   - 摘要包含不属于原文的内容 = 0分

4. **信息质量**（1分/0分）
   - 无可读性问题（标点、符号、错别字等）且无重复性问题 = 1分
   - 存在可读性或重复性问题 = 0分

## 参数配置

脚本测试了以下5种参数配置：

| 配置名称 | Temperature | Top P | Top K |
|---------|-------------|-------|-------|
| 低温度高精确 | 0.1 | 0.9 | 40 |
| 中温度均衡 | 0.5 | 0.8 | 30 |
| 高温度创意 | 0.8 | 0.6 | 20 |
| 低温完整采样 | 0.3 | 1.0 | 50 |
| 高温缩小范围 | 0.7 | 0.7 | 10 |

## 使用方法

1. 确保安装了所需的依赖包：
   ```
   pip install pandas matplotlib tqdm openai tiktoken
   ```

2. 设置OpenAI API密钥：
   ```
   set OPENAI_API_KEY=你的API密钥
   ```

3. 准备测试文档：
   - 将测试文档放置在 `D:\文档摘要测试` 目录下
   - 支持的文档格式：PDF、DOCX、TXT、MD等

4. 运行评估脚本：
   ```
   python summary_evaluation.py
   ```
   或直接双击 `run_evaluation.bat`

## 输出结果

评估完成后，将生成以下文件：

1. `summary_evaluation_报告时间戳.csv` - 包含所有评估详细数据的CSV文件
2. `summary_evaluation_report_报告时间戳.md` - Markdown格式的评估报告
3. `summary_evaluation_total_报告时间戳.png` - 总分对比图表
4. `summary_evaluation_metrics_报告时间戳.png` - 各指标对比图表

## 注意事项

1. 评估过程可能会消耗大量API调用，请注意控制成本
2. 对于较大的文档，处理时间可能较长
3. 确保测试文档具有足够的代表性
